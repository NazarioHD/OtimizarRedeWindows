# 🎮 Otimizador de Rede para Jogos

Um script `.bat` desenvolvido para **limpar, resetar e renovar configurações de rede do Windows**, ajudando a solucionar problemas comuns de conexão, DNS, Winsock, TCP/IP e DHCP.


## 🚀 Recursos

* 🧹 Limpeza do cache DNS
* 🔄 Renovação do endereço IP/DHCP
* 🌐 Reset do Winsock
* 🌐 Reset do TCP/IP
* 🔧 Reset do IPv4
* 🔧 Reset do IPv6
* 🗂️ Limpeza do cache ARP
* 🛣️ Limpeza da tabela de rotas
* 🔐 Reset do proxy WinHTTP
* 🖥️ Limpeza do cache NetBIOS
* 🔄 Nova limpeza do DNS
* 📋 Exibição das configurações de rede

## 📋 Requisitos

* Windows
* Permissão de Administrador
* Conexão de rede

## 📥 Instalação

1. Baixe o arquivo `.bat`.
2. Clique com o botão direito no arquivo.
3. Selecione **Executar como administrador**.
4. Aguarde o processo terminar.
5. Reinicie o computador.

## ⚙️ Comandos utilizados

O script utiliza ferramentas nativas do Windows, incluindo:

```text
ipconfig
netsh
arp
route
nbtstat
```

Não é necessário instalar programas adicionais.

## 🎯 Para que serve?

O script pode ser útil quando você está enfrentando problemas como:

* DNS com problemas
* Internet que não conecta corretamente
* Problemas para obter IP
* Erros relacionados ao Winsock
* Problemas na pilha TCP/IP
* Problemas de conexão após alterações de rede
* Falhas de comunicação com servidores de jogos

Após finalizar o script:

```text
1. Reinicie o computador
2. Conecte-se novamente à internet
3. Abra seu jogo
4. Verifique o ping
5. Observe se houve melhora na estabilidade
```
